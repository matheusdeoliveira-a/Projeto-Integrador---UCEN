# UCEN — Universidade de Ciências Exatas Nebula&#x20;

Projeto Integrador do curso Técnico em Informática do Senac Lapa Tito, desenvolvido com Rafael Hidemitsu e Ruan Toledo.

A UCEN é uma universidade fictícia criada para aplicar conhecimentos de desenvolvimento web, banco de dados e infraestrutura, com foco em ética, acessibilidade e respeito.

## Acesse o projeto

- **Site:** [https://nebula-ucen.duckdns.org/Nebula/Nebula/](https://nebula-ucen.duckdns.org/Nebula/Nebula/)
- **Apresentação:** [https://canva.link/82qjxjopogxryve](https://canva.link/82qjxjopogxryve)

*O site depende da instância AWS EC2 estar ligada.*

## Funcionalidades

- **Home:** informações institucionais, graduações, acessibilidade, autenticação, ingresso e assistente de IA Sirius.
- **Portal do Aluno:** calendário, materiais, dados pessoais e chamados.
- **Portal do Professor:** turmas, materiais e agenda acadêmica.
- **Portal do Suporte:** gerenciamento de usuários, documentos, chamados, e-mails e relatórios.

## Tecnologias

HTML5, CSS3, JavaScript, PHP, MariaDB, Adminer, Apache, AWS EC2, Amazon Linux 2023, DuckDNS, HTTPS e PHPMailer. O assistente Sirius utiliza o Google AI Studio.

## Aprendizados

Desenvolvimento web, integração com banco de dados, operações CRUD, gerenciamento de usuários, hospedagem Linux na AWS e trabalho em equipe.

## Observação

Projeto acadêmico demonstrativo. Pagamentos, certificados e notas semestrais são funcionalidades fictícias, sem integração com processos reais.

Por segurança, credenciais e chaves de API foram substituídas por marcadores no código.
